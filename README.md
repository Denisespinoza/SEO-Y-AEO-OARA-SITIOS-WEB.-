# SEO y AEO para sitios web — paquete para moldey.com

Investigación y plan para mejorar la visibilidad global de **moldey.com** (moldes digitales de costura) en buscadores (SEO) y en
respuestas de IA (AEO/GEO), por oleadas, hasta cubrir los 100 idiomas más hablados.

**Estado: en construcción.** Esta es una primera subida con la lista de idiomas, los scripts y las instrucciones de investigación.
Los informes finales y el prompt maestro para Claude Code se agregan en los próximos commits.

## Contenido actual
- `data/idiomas-master.csv` — 100 idiomas (aproximadamente por total de hablantes) + 13 extras relevantes para moldería, con código web (BCP-47), escritura y dirección.
- `scripts/` — consolidar terminología, generar sitemaps con hreflang y validar hreflang (solo Python estándar).
- `research/raw/` — instrucciones y salidas crudas de la investigación (se irán completando).
